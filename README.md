# xpanzia

Documentos de las cuentas de Meta de BetPro (Honduras) y Astrobet (Ecuador). Abrir `index.html` o servir la carpeta con `python3 -m http.server`.

- `betpro/`: diagnóstico de la cuenta de Meta.
- `astrobet/`: análisis de la cuenta de Meta (ene a sep 2026) e informe creativo (ene a oct 2026).
- `assets/`: sistema de diseño compartido.
